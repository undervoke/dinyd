# Anchors

The [README](../README.md#anchors) owns the anchor, selector, unit, link, and digest contract.
Deriving a [link's existence reference](../README.md#links)<!-- dinyd: #link-resolution d1:8f60f27009e6621c -->, and the path of an [anchor bound](../README.md#bound-anchors)<!-- dinyd: #bound-anchors d1:1d50430851deec92 --> to it, from its written destination avoids a separately maintained path drifting from the link.
The code → claim direction is obtained by scanning documents.
Selectors never name line numbers.
`s1` hashes tokens and nesting, not node kind names.
A unit's pairing errors surface on each document that references it; unreferenced units stay silent.
[Locks](lock.md) own how their markers project out of a `d1` unit.
